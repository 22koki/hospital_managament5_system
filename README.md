# 🏥 Hospital Management System

A web-based Hospital Management System developed to simplify
the management of patients, doctors, appointments and other
hospital operations.

## ✨ Features

- 👤 Patient registration and management
- 👨‍⚕️ Doctor management
- 📅 Appointment booking
- 🔎 Doctor search
- 🛡️ Administrative panel
- 📞 Contact functionality

## 🛠️ Tech Stack

- PHP
- HTML
- CSS
- MySQL
- Composer

## 🎯 Purpose

This project was developed to demonstrate the implementation
of a database-driven healthcare management application.

It provides an interface through which hospital information
can be organized and managed while demonstrating backend
development, database integration and CRUD concepts.

## 📂 Project Structure

- `admin-panel.php` — Administrative dashboard
- `doctor-panel.php` — Doctor dashboard
- `appointment.php` — Appointment management
- `doctorsearch.php` — Doctor search functionality
- `contact.php` — Contact functionality

## 🚀 Getting Started

1. Clone this repository.
2. Configure a local PHP development environment.
3. Import the project database into MySQL.
4. Configure the database connection.
5. Start the application through your local web server.
